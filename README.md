
# 🐍 Gusanito Algebraico

¡Aprender álgebra nunca fue tan divertido!

Gusanito Algebraico es un juego educativo interactivo diseñado para estudiantes de segundo año de secundaria. Combina el clásico juego Snake con desafíos matemáticos para aprender álgebra mientras juegas.

## 🎮 ¿Cómo se juega?

- Controla al gusanito utilizando las flechas del teclado.
- Come manzanas para crecer y ganar puntos.
- Evita chocar contra las paredes y contra tu propio cuerpo.
- Responde preguntas de álgebra para conseguir puntos adicionales.
- Utiliza las pistas cuando necesites ayuda.

## 🧠 Temas de aprendizaje

- Variables y coeficientes.
- Expresiones algebraicas.
- Reducción de términos semejantes.
- Sustitución de valores.
- Ecuaciones básicas.
- Propiedad distributiva.

## 🏆 Características

- Tres velocidades de juego.
- Preguntas con cuatro alternativas.
- Pistas y explicaciones.
- Sistema de puntuación.
- Logros y recompensas.
- Diseño adaptable a diferentes pantallas.

## 🚀 ¿Cómo jugar?

Una vez publicado mediante GitHub Pages, podrás acceder al juego desde tu navegador web.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Canvas API

## 📚 Objetivo

Promover el aprendizaje del álgebra mediante el juego, la práctica y la motivación.

¡Aprende, juega y conviértete en un Maestro de la X! 🏅
